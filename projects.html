VizWiz Salient Object Detection for Visual Accessibility

GitHub
  • Developed a deep learning pipeline for salient object detection using the VizWiz dataset, which contains real-world images captured by blind and low-vision users under challenging conditions such as motion blur, poor lighting, cluttered backgrounds, and off-center objects.
  • Implemented a U-Net encoder-decoder segmentation architecture in PyTorch to generate pixel-level binary masks separating visually salient objects from image backgrounds.
  • Built an image preprocessing pipeline that converts polygon-based VizWiz annotations into binary segmentation masks using OpenCV and prepares images and masks for model training at 256 × 256 resolution.
  • Evaluated model configurations across batch size, optimizer, learning rate, and feature-size experiments to analyze their effects on training behavior and validation performance.
  • Explored future extensions including attention mechanisms, pretrained vision backbones, multi-scale feature extraction, and vision-language models for richer assistive visual understanding.

NYC Yellow Taxi Trips: EDA + Statistical Testing

GitHub
  • Analyzed approximately 3 million NYC Yellow Taxi trips from January 2024 to investigate how trip volume, distance, and fares vary by time of day and day of week.
  • Performed data curation and preprocessing in pandas, including type inspection, missing-value analysis, filtering, and outlier handling.
  • Created exploratory visualizations showing daily and hourly trip trends and weekday/hour distributions.
  • Tested whether trip distance differed by weekday using one-way ANOVA followed by Tukey HSD pairwise comparisons.
  • Evaluated fare-related hypotheses including average fare by hour and fare differences across payment types using statistical hypothesis testing.

Iniquity+ Compiler Extensions: Arity, Rest Args, case-lambda, apply

GitHub
  • Extended a Racket-based compiler for a small functional language, Iniquity+, by implementing runtime arity checking for function calls.
  • Added support for rest-argument functions by generating code to collect additional stack arguments into a proper list bound to the rest parameter.
  • Implemented case-lambda-style multi-arity dispatch to select function clauses at runtime based on the number of provided arguments.
  • Built the apply form, compiling calls that consume a runtime list and push its elements onto the stack before invoking the target function.
  • Validated behavior using targeted interpreter-guided tests covering arity mismatches, list construction, dispatch edge cases, and apply.
